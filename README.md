# SFM Cross-Network NIDS — Reproducibility Package

Code, notebooks, and compact result artifacts for the paper:

> **Semantic Feature Mapping and Few-Shot Calibration for Cross-Network Intrusion Detection**
> Hero Yudo Martono, Iwan Syarif, Ferry Astika Saputra
> Department of Informatics and Computer, Politeknik Elektronika Negeri Surabaya (PENS), Indonesia

This repository supports the reproducibility of the experiments. All numbers in the
manuscript are derived from the notebooks and artifacts here. No fabricated values.

## What this repository contains

- `paper1a-english.tex` — manuscript source (LaTeX, Elsevier/JISA format).
- `figure-q1/` — figures used in the manuscript.
- `*.tex` (figures/highlights/graphical abstract) + `make_figures.py` — figure sources.
- `*.json` — compact result artifacts (tables/metrics) produced by the notebooks.
- `notebooks/` — analysis notebooks (feature mapping, cross-dataset baseline,
  alignment, domain adaptation / few-shot calibration, Wasserstein distribution
  shift, ablation, multi-seed CI, multiclass, AWS real-traffic validation).
- `notebooks/{mapping_out,fewshot_out,shift_out,aws_labeled}/` — extracted flow
  features and intermediate CSV/PNG results (compact, de-identified).
- `aws/` — infrastructure-as-code and scripts for the real-traffic AWS validation
  (VPC/EC2 templates, traffic generation, feature extraction, runbook).

## Datasets

The two public benchmark datasets are **not redistributed here**; obtain them from
their official providers:

- **CSE-CIC-IDS2018** — Canadian Institute for Cybersecurity (CIC).
- **UNSW-NB15** — UNSW Canberra.

The AWS real-traffic validation flows were generated by the authors in a controlled,
isolated VPC (`ap-southeast-1`); only aggregated flow features are released (no raw
packet payloads, no personal data).
